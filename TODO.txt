Quote pseudocode:
Precompute Edit regions
For each computed state, from the newly implemented edit section to start of next edit section (suppose i just applied first edit: aa aa cc -> aa bb cc. Then we consider region from first b to space before c), basically whatever indices are valid on the same line, but before next edit.
If the first quote is right before the edit region, and the next quote is right after the edit region, then we can do a di"/ci" -> pure insert, no need to search
if the first quote is the first char in edit region, and next quote is last char in edit regino, then we can do a da"/ci" -> pure insert, no need to search
If the first/second quote are inside the edit region otherwise, then we can use a ca". -> 
will need to search starting from insert mode (adds short exploration of backspace/deletes, or fall back to escape + normal exploration)
Otherwise, first quote is somewhere before next edit start. Then it is never possible to use ".

We can apply a similar logic to brackets. Begin at start of newly implemented edit section, search to end of next edit section:
First special case: if can do dib/cib -> pure insert, no need to search
Second special case: if can do dab,cib -> pure insert, no need to search
If first opening / next closing bracket inside the edit region otherwise, then we can use cab -> deletes, or fall back to escape + normal exploration 
Otherwise, containing bracket pair contains space before next edit start.

Then, when searching after applying an edit, we can simply check from the just-completed edit section whether we can do a bracket action or not.
